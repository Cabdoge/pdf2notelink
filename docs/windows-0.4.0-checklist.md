# Windows 11：0.4.0 阅读位置检查

安装发布包 `pdf2notelink-0.4.0.xpi`，记录 Zotero 版本。使用主窗口 PDF 标签页；准备带有较长正文、图片及位于中后部高亮引用的笔记，并准备零篇、单篇、多篇关联的高亮。

1. 升级后默认仍为“定位到高亮引用”；原有点击触发方式保持不变。
2. 选择“从笔记开头阅读”：设置本身不移动当前笔记；下次点击后回到顶部。
3. 将笔记滚动到中部，再点击同一高亮或指向同一笔记的另一高亮：再次回到顶部。
4. 从多个候选中选择子笔记或独立笔记，均从开头阅读；无关联时不改变当前笔记。
5. 改为 Ctrl＋点击模式：普通点击仍可编辑批注评论，Ctrl＋点击按所选阅读位置打开笔记。
6. 切回引用模式：定位第一处对应引用；重复引用不会定位到无关文字。
7. 快速点击不同高亮、切换 PDF 标签页和切换设置：旧请求不再改变当前阅读位置，候选浮层正确关闭。
8. 编辑笔记后切换高亮：内容已保存，引用身份保留，滚动不改写正文。
9. 重启 Zotero、停用／重新启用插件：两组设置均保留，打开行为正确。
10. 图片加载后笔记仍处于所选阅读位置，无意外跳回旧位置。

后续回归时请记录具体 Zotero 版本、通过的项目及异常表现。0.4.0 的 Windows 11 验证状态见 [验证记录](../TESTING.md)。
