# Windows 11：0.3.0 检查

安装 0.3.0 XPI：Zotero → 工具 → 插件 → 齿轮菜单 → 从文件安装插件。记录 Zotero 的具体版本和本页各项结果。

准备三个高亮，分别关联零篇、一篇、两篇笔记；至少一个高亮带有批注评论。通过拖入高亮或“从批注添加笔记”建立原生引用。

1. 设置 → pdf2notelink：确认默认选中“直接点击高亮”；单击仍按原方式打开笔记。
2. 选中“Ctrl＋点击高亮”，关闭设置：普通点击只显示批注评论，不打开或替换当前笔记。
3. 编辑批注评论，点击其他位置再返回：确认评论已保存。
4. Ctrl＋点击仅关联一篇笔记的高亮：打开正确笔记并定位；对已选中的同一高亮重复操作仍有效。
5. Ctrl＋点击关联两篇笔记的高亮：高亮旁显示候选列表；选择后正确打开笔记。
6. Ctrl＋点击无关联高亮：不显示额外提示，也不展开笔记栏。
7. 拖动高亮、Ctrl＋Shift＋点击不打开关联笔记；左侧批注列表仍可用 Ctrl＋点击多选。
8. 候选列表打开时切回“直接点击”：列表关闭，新的设置立即生效；在另一个 PDF 标签页也生效。
9. 选择组合键模式并重启 Zotero：设置仍被选中，普通点击与 Ctrl＋点击仍按上述规则工作。
10. 停用并重新启用插件：设置页面恢复，触发方式保留，没有重复候选浮层；编辑笔记后切换高亮，内容正常保存。
